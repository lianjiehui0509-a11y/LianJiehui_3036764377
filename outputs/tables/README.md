# Tables

Generated result tables are saved in this folder by `code/run_all.py`:

- `table2_means.csv` — Table 2 (means of key variables)
- `table3_did.csv` — Table 3 (difference-in-differences)
- `table4_regressions.csv` — Table 4 (reduced-form models)
- `table5_robustness.csv` — Table 5 (robustness checks)
- `table7_prices.csv` — Table 7 (price effects)
- `first_stage_wage.csv` — first-stage wage regression
- `extension_chain_did.csv` / `extension_chain_descriptives.csv` — extension
- `results_summary.md` — consolidated summary of all estimates
