# AI-Use Disclosure

This project used an AI assistant (Claude, via the Claude Code CLI) throughout
the workflow, as permitted by the assignment. This document records where and
how AI was used, how AI-generated outputs were checked, and which AI
suggestions were corrected or rejected.

## Where and how AI was used

| Stage | What the AI did |
|---|---|
| Understanding the paper | Extracted and summarised the methodology from the Card & Krueger (1994) PDF: the FTE definition, the GAP variable, the sample-coding rules for closed and temporarily closed stores, the regression specifications, and the list of "to be replicated" tables. |
| Data and variable construction | Drafted Python code to load `public.csv`, construct FTE, GAP, full-meal price, and chain/ownership/region dummies, and to code wave-2 employment for closed stores. |
| Core replication | Drafted and ran the difference-in-differences estimator, the Table 4 regressions, the first-stage wage regression, the price regressions (Table 7), and the robustness checks (Table 5), and generated Figure 1. |
| Independent extension | Drafted the chain-heterogeneity analysis: split-sample DID, pooled `chain × NJ` and `chain × GAP` interaction models with an F-test. |
| Writing | Drafted the report structure and prose. The tables and figure are generated by code, not written by hand. |
| Repository and tooling | Set up the repository structure, the reproducible workflow (`code/run_all.py`), the Git history, and the PDF rendering pipeline (pandoc + tectonic). |

## How AI-generated code, analysis, and writing were checked

1. **Every headline number was verified against the paper.** The replicated
   coefficients and standard errors for Table 4 columns (i)–(iv) (2.33/1.19,
   2.30/1.20, 15.65/6.08, 14.92/6.21), the regression-sample size (357), the
   dependent-variable moments (−0.24, 8.83), and the first-stage wage regression
   (1.04, R² = 0.77) were compared one by one with the published tables.
2. **Intermediate objects were inspected**, not just final output: the
   chain × state cell counts, the 410 → 399 → 384 → 357 sample flow, and the NJ
   wage-band classification (101 / 140 / 73) were all checked against the paper.
3. **The workflow is reproducible.** The script was re-run from scratch after
   each change, and a clean run (no warnings, stable output) was confirmed.
4. **Plausibility of the extension** was checked against the descriptive
   statistics (KFC's much smaller mean FTE of 12.7 vs ≈ 23 elsewhere) before the
   interaction result was interpreted.

## Important AI errors or suggestions that were corrected or rejected

1. **Duplicate region columns (corrected).** The first draft of the script
   re-concatenated `NORTHJ/CENTRALJ/PA1/PA2`, which already exist in
   `public.csv`, producing duplicate columns and a rank-deficient design matrix
   for Table 4 column (v). This was detected via a singular-matrix warning,
   traced to the duplicated columns, and fixed. The region-adjusted GAP
   coefficient changed from a corrupted value to 11.98, close to the paper's
   11.91.
2. **Regression-sample definition (corrected).** An initial draft restricted the
   Table 4 sample to stores with a wave-2 wage, yielding 351 stores and a
   dependent-variable mean of −0.03 instead of the paper's 357 and −0.237.
   Re-reading the paper showed that permanently closed stores must be retained
   (they cannot report a wave-2 wage but are coded as zero employment). The
   corrected rule reproduces 357 stores exactly.
3. **Publication of restricted data (caught and fixed).** An earlier version
   committed the store-level processed dataset (`output/processed/…`) alongside
   the raw data. This would have redistributed restricted teaching data, so the
   repository was rebuilt to exclude all store-level data from version control,
   keeping only aggregate results.
4. **Unicode subscripts in the report (corrected).** The report draft used
   Unicode subscript characters (FTE₁, FTE₂) that the LaTeX PDF engine could not
   render; these were replaced before the final PDF was produced.
5. **Rank-deficient extension regression for one chain (rejected).** For a chain
   with no variation in company ownership, the ownership control is collinear;
   the script drops it rather than fitting a singular model.
6. **Region-coding ambiguity (documented, not "fixed").** The paper's Table 4
   note says "two regions" of New Jersey while the text lists three. The script
   uses the three-region partition and documents the resulting 0.07 difference
   in column (v); no attempt was made to force an exact match through an
   undocumented specification.

No AI output was accepted without verification against the source paper or the
raw data.
