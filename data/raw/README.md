# Raw data

Place the original input data file here:

```
data/raw/public.csv
```

`public.csv` is the Princeton public replication dataset for Card & Krueger
(1994): 410 fast-food restaurants in New Jersey and eastern Pennsylvania,
surveyed in February–March 1992 and November–December 1992.

## How to obtain it

Download Package **01 — Minimum wage / DID** from the course "Project Data
Downloads" page (ECON6067), and copy the `public.csv` inside the extracted
folder to this location, keeping the filename unchanged.

## Data-access terms

These data are provided for ECON6067 teaching and coursework only. Do not
redistribute them, upload them to public repositories, or use them
commercially. The raw file is therefore **not** committed to this repository;
it is placed locally and regenerated outputs are kept out of version control
(see `.gitignore`).
