# Minimum Wages and Employment — Replication of Card & Krueger (1994)

A reproducible, AI-assisted replication and extension of

> Card, David, and Alan B. Krueger (1994). "Minimum Wages and Employment: A
> Case Study of the Fast-Food Industry in New Jersey and Pennsylvania."
> *American Economic Review*, 84(4), 772–793.

Prepared for ECON6067 · Quantitative Tools for Economic Analysis (Individual
Project 01 — Minimum Wage / Difference-in-Differences).

## What this project does

It reconstructs the Card–Krueger analysis from the Princeton public replication
data and reproduces the assigned **Tables 2–4 and Figure 1**, plus a
**first-stage wage check**, the **price regressions (Table 7)**, **robustness
checks (Table 5)**, and one **independent extension** (chain heterogeneity in
the employment response).

The headline result reproduces the paper's: a difference-in-differences estimate
of **+2.75 FTE employees (t = 2.05)** vs the published **+2.76 (t = 2.03)**, and
Table 4 coefficients matching to two decimals (e.g., New Jersey dummy **2.30,
SE 1.20**).

## How to reproduce (step by step)

These steps are written so that a fresh environment — a grader or an AI agent —
can reproduce every number from scratch.

### 1. Obtain and place the raw data

The raw data are **restricted teaching data** and are **not** committed to this
public repository. Download Package **01 — Minimum wage / DID** from the course
"Project Data Downloads" page, then place the file at:

```
data/raw/public.csv
```

Keep the filename unchanged. (Column definitions are in `DATA_DICTIONARY.md`.)

### 2. Install dependencies

Requires Python 3.10 or later.

```bash
pip install pandas numpy scipy statsmodels matplotlib
```

### 3. Run the workflow

```bash
python code/run_all.py
```

This single command regenerates **every** table and figure:

- `outputs/tables/` — `table2_means.csv`, `table3_did.csv`,
  `table4_regressions.csv`, `table4_detail.csv`, `table5_robustness.csv`,
  `table7_prices.csv`, `first_stage_wage.csv`, `extension_chain_did.csv`,
  `extension_chain_descriptives.csv`, and `results_summary.md`
- `outputs/figures/figure1_wage_distribution.png` — Figure 1
- `data/processed/ck1994_analysis.csv` — the processed analysis dataset (local
  only)

The script prints a console summary of the key estimates. No manual editing of
the data or code is required.

### 4. Verify against the paper

The expected values are documented in `skills/SKILL.md` and in the report. In
particular: DID = +2.75 (SE 1.34, t = 2.05); Table 4 columns (i)–(iv) = 2.33
(1.19), 2.30 (1.20), 15.65 (6.08), 14.92 (6.21); regression sample = 357 stores;
first-stage wage-gap coefficient = 1.04 with R² = 0.77.

## Data access

`public.csv` is the Princeton public replication dataset for Card & Krueger
(1994): 410 fast-food restaurants in New Jersey and eastern Pennsylvania,
surveyed in February–March 1992 and November–December 1992. Per the course
data-access terms, the store-level data are **not** redistributed here: neither
`data/raw/public.csv` nor the processed dataset is committed. Only aggregate
results (the reproduced tables and Figure 1) are committed. See
`data/raw/README.md` for the download location and access terms.
